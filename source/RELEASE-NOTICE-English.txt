# Godfall Equipment Editor — Beta Release Notice

Godfall Equipment Editor · 0.1.0
Author: 高斯定理 / Gauss Theorem

This is a free, unofficial player-made tool for personal equipment research, trait editing and loadout planning in single-player Godfall. It is currently a small-scale beta. Feedback and suggestions are welcome.

## Main features

- Browse armory equipment, augments and saved armor loadouts.
- Filter and sort by name, type, rarity, traits and other conditions.
- Choose supported trait types and values within normal game ranges.
- Create modified copies while retaining originals, including batch plans.
- Chinese and English interfaces with bundled runtimes; no separate Python or Node.js installation required.

Support varies by item, upgrade rank and special variant. Follow the candidates, restrictions and messages shown in the tool. Some features remain experimental.

## Testing scope and use

This version has been tested on the author's PC with a fresh tool directory for first launch, armory reading and plan compilation, without importing the old tool's historical inventory or edit plans.

This does not establish compatibility with every PC, game version or player save. Unsupported game versions may not work, and other storefront versions have not all been verified.

Before use:

1. Make a separate game-save backup. Tool patch/settings backups do not replace save backups.
2. Extract the whole package and select your own game folder as described in the included instructions.
3. Start by testing one ordinary, non-essential item before wider use.
4. Close the game normally before installing or disabling a patch.
5. "Generated" does not mean picked up and saved. Pick up normally and verify in the armory.
6. Disabling the patch does not automatically delete copies already saved by the game or reverse saved curse completions.

Use the tool in your personal single-player environment and avoid affecting other players' experience. This beta may have compatibility problems or unexpected results. The author will work on reported issues but does not guarantee operation in every environment.
